# streamly

Стриминговый сервис на Go: смотрите и слушайте контент в потоковом режиме без лишних ожиданий.

## Возможности

- Потоковая передача видео/аудио
- Каталог контента с поиском
- Регистрация и авторизация пользователей
- REST API

> Проект в активной разработке, список возможностей будет расширяться.

## Стек

- Go
- Git

## Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-ник/streamly.git
   cd streamly
   ```

2. Установите зависимости:
   ```bash
   go mod tidy
   ```

3. Запустите сервер:
   ```bash
   go run .
   ```

По умолчанию сервис доступен по адресу `http://localhost:8080`.
